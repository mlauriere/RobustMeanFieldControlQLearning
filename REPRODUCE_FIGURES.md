# Reproducing Paper Figures

All main paper figures can be regenerated from the included aggregate data.

## Single Command

```bash
python paper_experiments/make_paper_figures.py
```

Outputs are written to `paper_figures/` as PNG and PDF.  The script
regenerates:

## Figures Regenerated from Aggregates

### Robustness Profiles (main paper)
- **Input**: `paper_results/final_policy_costs.csv`
- **Script**: `paper_experiments/make_paper_figures.py`
- **Output**: `paper_figures/main_profiles_{sysrisk,sis,seir}.{png,pdf}`
- **Conventions**: expected discounted reward (negated cost), robustness
  radius m, eval. drift zeta, solid sampled curves with bootstrap
  uncertainty bands, dashed idealized finite-grid references, no figure
  titles.

### Q-Function Convergence (main paper)
- **Input**: `paper_results/convergence_summary.csv`
- **Script**: `paper_experiments/make_paper_figures.py`
- **Output**: `paper_figures/convergence_q_error.{png,pdf}`
- **Conventions**: log-log scale, median over seeds with 10th/90th
  percentile bands, theorem-aligned guide curve, per-example subplots.

### Relative Improvement (supplementary)
- **Input**: `paper_results/relative_improvements.csv`
- **Script**: `paper_experiments/make_paper_figures.py`
- **Output**: `paper_figures/relative_improvement_{sysrisk,sis,seir}.{png,pdf}`

## Prebuilt HPC Assets (included, not regenerated by this script)

The following figures are included as prebuilt HPC-generated assets in
`paper_figures/`.  They require the full HPC campaign outputs to
regenerate from scratch:

- **Convergence diagnostics**: `convergence_policy_gap*.{png,pdf}`,
  `convergence_coverage.{png,pdf}`, `convergence_idealized_residuals.{png,pdf}`,
  `convergence_theorem_rate.{png,pdf}`
- **Idealized cost landscapes**: `idealized_landscape_*.{png,pdf}`
- **Grid sensitivity**: `grid_sensitivity.{png,pdf}`
- **Hyperparameter screen**: `hyperparameter_screen_sysrisk.{png,pdf}`
- **Policy disagreement**: `policy_disagreement.{png,pdf}`
- **Low-radius Systemic Risk add-on**: `sysrisk_low_radius_*.{png,pdf}`

To regenerate prebuilt figures, run the full HPC collector after
completing raw runs:

```bash
python paper_experiments/collect_hpc_results.py
```

## Notes

- Figure regeneration from aggregates runs on a laptop in < 2 minutes.
- Full reruns of the HPC experiments require an HPC cluster. See `HPC.md`.
- The aggregate files in `paper_results/` are the source of truth for paper
  numbers. Do not hand-edit values.
