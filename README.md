# Robust Mean-Field Control Q-Learning — Reproducibility Code

Reference implementation for the paper "Robust Mean-Field Control via Q-Learning".

This repository provides the finite-grid robust Q-learning algorithm, example
environments (Systemic Risk, SIS, SEIR), aggregate data used for paper figures,
and scripts to regenerate those figures.

## What Is Included

- `engine/` — Core solver: table construction, robust dual, Bellman targets,
  asynchronous Q-learning, policy evaluation, convergence diagnostics.
- `examples/` — Three example environments with local run scripts.
- `paper_results/` — Aggregate CSV data used to produce paper figures and tables.
- `paper_figures/` — Paper figures and supplementary diagnostics (PNG and PDF).
- `paper_experiments/` — Scripts to regenerate figures from aggregates and to
  run HPC campaigns.
- `run_sanity_checks.py` — Fast confidence checks (laptop, under a minute).

## Figure Classification

### Main Paper Figures (regenerated by `make_paper_figures.py`)

- `main_profiles_{sysrisk,sis,seir}.{png,pdf}` — Robustness profiles:
  expected discounted reward vs robustness radius m, sampled Algorithm 1
  curves (solid) with uncertainty bands, idealized finite-grid references
  (dashed).  Convention: reward (negated cost), x-axis "robustness radius m",
  legend "eval. drift zeta".
- `convergence_q_error.{png,pdf}` — Q-function convergence: sup-norm
  error vs sampled updates on log-log scale, median over seeds with
  10th/90th percentile bands, theorem-aligned guide curve.

### Supplementary Diagnostics (prebuilt HPC assets)

- `relative_improvement_*.{png,pdf}` — Relative improvement over non-robust
  baseline (also regenerated by `make_paper_figures.py`).
- `convergence_policy_gap*.{png,pdf}` — Policy-cost gap convergence.
- `convergence_coverage.{png,pdf}` — State-action coverage.
- `convergence_idealized_residuals.{png,pdf}` — Idealized Bellman residuals.
- `convergence_theorem_rate.{png,pdf}` — Theorem-aligned rate diagnostic.
- `idealized_landscape_*.{png,pdf}` — Idealized cost landscapes.
- `grid_sensitivity.{png,pdf}` — Grid-size sensitivity.
- `hyperparameter_screen_sysrisk.{png,pdf}` — Hyperparameter screening.
- `policy_disagreement.{png,pdf}` — Policy-level disagreement.
- `sysrisk_low_radius_*.{png,pdf}` — Low-radius Systemic Risk add-on.

## Quick Start

```bash
# Create conda environment
conda env create -f environment.yml
conda activate robust-mfc

# Run sanity checks
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python run_sanity_checks.py
```

## Reproduce Figures

```bash
# Regenerate main paper figures and convergence from included aggregate data
python paper_experiments/make_paper_figures.py
```

Figures are written directly to `paper_figures/` (PNG + PDF).  The regenerated
figures overwrite the prebuilt main-profile and convergence figures with
bitwise-identical or visually-equivalent versions; supplementary diagnostics
are left untouched.

## Expected Runtime

- Sanity checks: < 1 minute on a laptop.
- Figure regeneration from aggregates: < 2 minutes.
- Full sampled experiments: HPC-scale (see `HPC.md`).

## Dependencies

- Python >= 3.9, < 3.13
- NumPy >= 1.24
- SciPy >= 1.10
- Matplotlib >= 3.7

See `REPRODUCE_FIGURES.md` for per-figure details and `ALGORITHM.md` for a
mapping between code and the paper's Algorithm 1.
